# TravelForge frontend

React + TypeScript + Vite user interface. It currently demonstrates the trip planning screen only; submit state is local and does not save a trip or call a planning service.

## Run locally

Install a current Node.js LTS release, then run:

```sh
npm install
npm run dev
```

Create a production bundle with `npm run build`.

See [`../docs/IMPLEMENTATION_NOTES.md`](../docs/IMPLEMENTATION_NOTES.md) for design decisions, planned application logic, and reference websites.
